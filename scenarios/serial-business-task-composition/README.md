# Serial business task composition scenario

The project-authored MIT [BPMN model](process.bpmn) and [answer-free scenario](scenario.json) review an invoice, validate it, classify it and complete final human review. The exact [source overlay](source-overlay.json) binds the named operations to caller-supplied Activity handlers without changing source identity.

The [normative profile](../../profiles/cibseven-2.2.0/profile.json) and [semantics specification](../../docs/kernel/semantics/DATA-SEMANTICS-SPEC.md) bound the meaning. This retained engine regression model selects Lean, the TypeScript kernel and Temporal comparison; CIB supplies separately classified calibration only, with no whole-profile CIB target or retained CIB result. It has no production browser journey or catalog eligibility.

The separate [public-delivery scenario](public-delivery.scenario.json) binds the exact [metadata-bearing source](../../packages/bpmn-source/test/fixtures/business-public-delivery/serial-invoice.bpmn) and the same overlay/profile. Both human tasks carry the literal `reviewers` group and string `request` field; the final task submits the current request unchanged, matching the public Work journey. The [publication semantics](../../docs/kernel/semantics/PUBLICATION-AND-OBSERVATION-SEMANTICS-SPEC.md) owns its reviewed-composition relationship, configured host and qualification.
