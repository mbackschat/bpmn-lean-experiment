This retained engine regression model selects Lean, the TypeScript semantic core and Temporal comparison; CIB supplies separately classified calibration only, with no whole-profile CIB target or retained CIB result. It has no production browser journey or catalog eligibility.

The [public-delivery proposal](../../docs/BUSINESS-PROCESS-PUBLIC-DELIVERY-PROPOSAL.md) owns its reviewed-composition relationship, configured host and qualification. Neutral input registration establishes neither public closure nor a whole-profile CIB result.
