# Mixed-task business Error scenario

The project-authored MIT [BPMN model](process.bpmn) and [answer-free scenario](scenario.json) correct missing invoice data, revise a policy-rejected invoice and complete final human review after successful validation. The exact [source overlay](source-overlay.json) binds the named operations to caller-supplied Activity handlers without changing source identity.

The [`cibseven-2.2.0` profile](../../profiles/cibseven-2.2.0/profile.json) and [semantics specification](../../docs/kernel/semantics/PROPAGATION-SEMANTICS-SPEC.md) bound the meaning. This retained engine regression model selects Lean, the TypeScript kernel and Temporal comparison; CIB supplies separately classified calibration only, with no whole-profile CIB target or retained CIB result. It has no production browser journey or catalog eligibility.

The separate [public-delivery scenario](public-delivery.scenario.json) binds the exact [metadata-bearing source](../../packages/bpmn-source/test/fixtures/business-public-delivery/invoice-error-recovery.bpmn) and the same overlay/profile. Every human occurrence carries the literal `reviewers` group and string `request` field; repeated reviews and finalization submit the current request unchanged after correction, matching the public Work journey. The [publication semantics](../../docs/kernel/semantics/PUBLICATION-AND-OBSERVATION-SEMANTICS-SPEC.md) owns its reviewed-composition relationship, recovery-handler configuration and qualification.
