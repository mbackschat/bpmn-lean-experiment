# Interrupting Activity boundary Message checkpoint source

This directory contains the exact [BPMN 2.0.2 source](process.bpmn) for the first-green checkpoint of the [interrupting Activity boundary Message proposal](../../docs/capsules/ACTIVITY-BOUNDARY-MESSAGE-PROPOSAL.md). One User Task owns one omission-only interrupting, payload-free, operation-addressed Message Boundary Event, and its normal and boundary routes reach distinct follow-on User Tasks.

The source is an admission and lowering fixture only. No answer-free scenario, registered product profile, differential case, Temporal scheduler, retained whole-model claim, or CIB target exists until the mandatory semantic-checkpoint review approves the implemented account.
