# Sequential Multi-Instance User Task scenarios

This directory contains one exact BPMN 2.0.2 batch-document-review source and two answer-free scenarios for the [Sequential Multi-Instance proposal](../../docs/capsules/SEQUENTIAL-MULTI-INSTANCE-PROPOSAL.md). The [natural scenario](natural.scenario.json) reviews three ordered items, submits one String result per generated inner User Task, and completes with an atomically published ordered output collection. The [interrupted scenario](interrupted.scenario.json) completes the first item, fires the one outer-lifetime `PT1S` Timer while the second task is active, submits that stale task identity to prove refusal, and leaves only the escalation route active. The focused live-refinement witness then completes that route outside the answer-free schedule, which must terminate at its first rejected command.

The Process input and final output use their exact `DataObjectReference` identities. Inner completion uses the exact scalar task `DataOutput` identity. Neither scenario carries an expected result, a winner annotation, a Temporal Run identity, or a CIB Multi-Instance target.
