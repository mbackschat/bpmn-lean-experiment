# Mapping order: sequential parameters, chained outputs and repeated targets

Answer-free schedules for [PC-DATA-05](../../../docs/PRACTICAL-CIB7-COVERAGE-TARGET.md#delivery-task-list) and [PC-DATA-06](../../../docs/PRACTICAL-CIB7-COVERAGE-TARGET.md#delivery-task-list): the order in which an element's `camunda:inputParameter` and `camunda:outputParameter` lists run. CIB runs each list one parameter at a time in document order and writes each output into the outer scope before it evaluates the next one in the inner scope; the [data semantics](../../../docs/kernel/semantics/DATA-SEMANTICS-SPEC.md#activity-data) own the account (CIB-EXT-0031), and the retained CIB Seven `2.2.0` answer is the target. The profile is `cibseven-2.2.0` with no source overlay.

| Model | Journey |
|---|---|
| [task-chained-outputs](task-chained-outputs.bpmn) | The User Task *Decide* maps `total` from `${amount}`, then `summary` from `${total}`; *Observe* publishes both. |
| [scope-chained-outputs](scope-chained-outputs.bpmn) | The Sub-Process *Pack* takes `amount` from `${incoming}` and maps `total` from `${amount}`, then `summary` from `${total}`; the Sub-Process *Shadow* also declares the local `level` (`inner`) and maps `level` from `${amount}`, then `shadowed` from `${level}`; *Observe* publishes all four. |
| [error-path-chained-outputs](error-path-chained-outputs.bpmn) | The Sub-Process *Pack* takes `amount` from `${incoming}` and maps `total` from `${amount}`, then `summary` from `${total}`; its task *Place* leads to an Error End Event that the interrupting Error boundary on *Pack* catches, and *Observe* after the boundary publishes both. |
| [installed-chained-outputs](installed-chained-outputs.bpmn) | The User Task *Decide* maps `total` from `mapped`, then `summary` from `${total}`; the User Task *Shadow* also declares the local `level` (`inner`) and maps `level` from `mapped`, then `shadowed` from `${level}`; *Observe* publishes all four. |
| [decision-chained-outputs](decision-chained-outputs.bpmn) | The decision task *Grade* evaluates [`gradeDecision`](decision-chained-outputs.dmn) into `grade` and maps `grade` from `mapped`, then `summary` from `${grade}`; the decision task *Shadow* evaluates it into its local `level` (`inner`) and maps `level` from `mapped`, then `shadowed` from `${level}`; *Observe* publishes all four. |
| [caught-chained-outputs](caught-chained-outputs.bpmn) | The Sub-Process *Pack* maps `total` from `mapped`, then `summary` from `${total}`; an Error End Event inside it is caught by its interrupting Error boundary, whose `camunda:errorCodeVariable` is `total`. The Sub-Process *Shadow* after it declares the local `level` (`inner`), maps `level` from `mapped`, then `shadowed` from `${level}`, and is left the same way through a boundary whose code variable is `level`; *Observe* publishes all four. |
| [task-caught-outputs](task-caught-outputs.bpmn) | Three Service Tasks fail in turn, each caught by its own interrupting Error boundary whose `camunda:errorCodeVariable` names the variable: *Collide* maps `code` from `mapped`, then `seenCollide` from `${code}`, and catches into `code`; *Read* maps `seenRead` from `${failure}` and catches into `failure`; *Local* declares the local `level` (`inner`), maps `seenLocal` from `${level}` and catches into `level`; *Observe* publishes `code` and `failure`. |
| [input-failure-order](input-failure-order.bpmn) | The User Task *Observe* has the input `first` from `${missing}`, a name nothing binds, then `second` from `${'1.5' + 1 > 2}`, a Double comparison. |
| [duplicate-targets](duplicate-targets.bpmn) | The User Task *Decide* has the inputs `x` from `first` and `x` from `second`, and the outputs `out` from `${x}`, `twice` from `first` and `twice` from `second`; *Observe* publishes `out` and `twice`. |
