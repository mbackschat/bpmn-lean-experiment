A second infrastructure correction is classified the same way: the doctor invocation in [the contributor-setup guard](../scripts/contributor-setup.test.ts) bounded a command that measures 5.9 to 6.9 seconds idle at ten seconds, so it reported a timeout as a doctor failure under the suite's concurrent runner. The bound is a hang guard rather than a performance budget and is widened; the covering guard is that test itself, which exercises the doctor on every infrastructure run.

The guards that read enumerated worktree paths read them through one tolerant reader, so a source deleted between enumeration and read is dropped rather than failing the scan. That correction is classified non-material under [the negative case](TESTING-SPEC.md#independent-cold-review-gate): it changes no BPMN meaning, profile, representation, observation, admission, transition family, or proof boundary, and it opens no review cycle. It is covered by [the Lean source-contract guard](../scripts/lean-source-contracts.test.ts), which owns the vanishing-source case, together with [the source-hygiene](../scripts/source-hygiene.test.ts) and [import-boundary](../scripts/lean-import-boundaries.test.ts) guards that consume the same reader.
