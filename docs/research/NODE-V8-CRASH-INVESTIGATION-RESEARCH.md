# Node and V8 native crash investigation

## Status

Investigated on 2026-09-28; cause unresolved. This is diagnostic research, not an adopted runtime change or proof that the product cannot run on Node.js. The RC owner accepted publishing with the disclosed intermittent qualification risk; final MUE runtime acceptance remains open.

## Mechanism assessment

The direct failure boundary is native V8 stack-root scanning during collection, below the BPMN semantic core. [Node issue #62393](https://github.com/nodejs/node/issues/62393) reports the same near-null fault, root-visitor frames and baseline-prologue frame on macOS arm64 with VM and worker-thread tests. [V8 change 0b94a9f](https://github.com/v8/v8/commit/0b94a9fd23ba5f59b3f675fb04d60a9b0102e27d) fixes a baseline prologue that saved an uninitialized dispatch-handle register on some configurations, leaving a random stack value discoverable by GC. That is a plausible causal mechanism for this signature, not proof that this particular Node build contains the bad code path or that the change fixes our crash. The matching frames establish where the invalid pointer was consumed, not where it originated. Temporal's sandbox, native SDK components, our allocation pattern, and Node/V8 integration have not been separated sufficiently to assign exclusive fault ownership. The async-hook abort is a different mechanism and remains independently open.

The earlier `--no-sparkplug` setting removed one observed baseline path and let a concurrent test lane pass; it was symptom suppression, not a demonstrated repair. The owner rejected that workaround. `--no-sparkplug` and `--no-parallel-scavenge` were removed from maintained Temporal test commands. With ordinary V8 settings, `./scripts/pnpm.sh run test:temporal:built` passed all 818 checks once (`/tmp/mue-temporal-unsuppressed-complete`, exit 0). This single pass establishes that the package can pass with those settings; it cannot establish that the intermittent native crash is gone. A transient Transaction-publication failure in earlier diagnosis later passed focused reruns and the package gate; no stable cause was demonstrated, so it is not folded into either native crash explanation.

## Remaining discriminator and release boundary

If the native fault recurs, retain the child process's exact command, Node/V8 version, macOS report hash and stack, and the smallest independently failing pair before changing flags or dependencies. Compare a matching supported Node build with and without the candidate V8 correction under the same diagnostic workload, or obtain an upstream-confirmed build/issue disposition; separately instrument the VM-timeout and async-hook boundary. An ordinary passing rerun, a feature-disabling flag, and the external stack match alone do not close either root cause.
