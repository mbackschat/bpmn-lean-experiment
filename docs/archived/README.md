# Archived documentation

This directory preserves resolved, superseded, or parked proposals and historical decision records that remain useful for rationale or reproducibility but no longer own a current contract or plan.

Current contracts live in active `-SPEC.md` documents. Current unimplemented intent lives in active `-PROPOSAL.md` documents. Immediate sequencing belongs in [PLAN.md](../PLAN.md), and exact implementation status belongs in [IMPLEMENTATION-MAP.md](../IMPLEMENTATION-MAP.md).
