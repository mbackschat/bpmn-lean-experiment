# Serial business task composition draft profile

The [profile artifact](profile.json) selects one finite root-scope serial chain with human work and named automated operations, immutable enclosing String/null input snapshots and complete local-result mappings. The [approved capsule](../../docs/capsules/SERIAL-BUSINESS-TASK-COMPOSITION-PROPOSAL.md) owns its full admission rules, name restrictions, guarantees and exclusions.

BPMN 2.0.2 supplies the normative execution authority. The retained `cibseven-2.2.0-` identity preserves the approved account; it does not declare an executable CIB oracle target. The listed [CIB relationships](../../docs/CIB-BPMN-RELATION-REGISTER.md) classify the bounded start/completion and exact-token mapping extensions. Calibration does not establish whole-profile CIB equivalence, general JUEL, CIB transaction timing or exactly-once external effects.
