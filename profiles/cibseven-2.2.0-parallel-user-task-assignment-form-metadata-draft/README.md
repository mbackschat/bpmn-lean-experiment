# CIB Seven 2.2.0 parallel User Task metadata draft profile

This draft profile composes the exact balanced two-branch Parallel Gateway lifecycle with two passive User Task metadata blocks. Each branch publishes its own literal group candidate and generated-form field, and either exact task may complete first while the other remains unchanged.

The [profile artifact](profile.json) pins CIB Seven `2.2.0` and admits only the reviewed six-edge fork, two-task, join topology. Process Start data, arbitrary parallel graphs, authorization, form validation, form-to-command binding, and general commutativity of overlapping completion patches remain excluded. The [parallel User Task metadata composition specification](../../docs/capsules/PARALLEL-USER-TASK-METADATA-COMPOSITION-SPEC.md) owns the complete selection and evidence boundary.

Its status remains `draft`. Results must not be reported as general parallel BPMN support, general resource assignment or form support, immutable CIB compatibility, or BPMN Process Execution Conformance.
