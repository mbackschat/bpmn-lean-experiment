# BPMN 2.0.2 Intermediate Catch Message draft profile

This standards profile selects one payload-free Intermediate Catch Message Event and one User Task in either finite acyclic linear order. The retained scenario selects Message then User Task; focused source, Lean, core, and Temporal witnesses cover the reverse order.

The complete meaning, direct subscription-address restriction, Signal refinement, evidence obligations, and exclusions are owned by the [Intermediate Catch Message capsule](../../docs/capsules/INTERMEDIATE-CATCH-MESSAGE-SPEC.md). The existing CIB relationship identifiers cover only the reused User Task premise; CIB is not a Message execution target for this profile.
