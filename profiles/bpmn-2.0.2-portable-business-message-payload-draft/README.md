# Portable business Message payload draft profile

The [profile artifact](profile.json) selects the [structured Message-payload amendment](../../docs/capsules/PORTABLE-BUSINESS-VALUES-PROPOSAL.md#structured-message-payload-consuming-amendment): the source structure of the [Message payload catch profile](../bpmn-2.0.2-message-payload-catch-draft/README.md) with a `SingletonBusinessItem` payload domain. One private executable Process has a None Start Event, one Intermediate Catch Message Event with one required `DataOutput` and one direct `DataOutputAssociation` into a distinct Process `Property`, one User Task and a None End Event. Admission follows that structure under any identifier or name spelling, and the `ItemDefinition` must leave `isCollection` absent, so the port is a noncollection port.

An occurrence-addressed `deliverPayloadMessage` carries exactly one `SingletonBusinessItem`: a String of at most 1,024 UTF-8 bytes, Null, Boolean, Integer, Decimal or Map of the portable value contract, never a root List or the legacy String list. The accepted delivery writes a copy of that value to the association's Property and withdraws the Message subscription atomically; an out-of-domain payload and a payload-free delivery are semantic rejections that leave the subscription live. Process Start and User Task completion keep empty value domains, so the delivered payload is the only external Process value. Every other profile keeps its own payload domain, and restoration under this profile requires every carried value to be in this domain.

The [retained shipment-manifest scenarios](../../scenarios/portable-business-message-payload/README.md) select Lean, TypeScript and Temporal with CIB absent. The inherited CIB relationship references `CIB-AGR-0001` and `CIB-OP-0001` bound only the User Task lifecycle and occurrence identity this profile reuses, exactly as in the closed profile; no CIB Message, portable-value or data-association claim follows. Hosting capacity, public registration and independent Closure are separate claims; the capsule owns current acceptance.
