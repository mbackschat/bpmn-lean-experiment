# Mixed-task control flow draft profile

The [profile artifact](profile.json) selects one root task graph with a single control unit, ordered Simple Boolean v1 choice, Exclusive Merge, task-separated rework and at most eight automatic steps per resumption. The [approved capsule](../../docs/capsules/MIXED-TASK-CONTROL-FLOW-PROPOSAL.md) owns its full admission rules, name restrictions, guarantees and exclusions.

BPMN 2.0.2 supplies the normative execution authority. The retained `cibseven-2.2.0-` identity preserves the approved account; it does not declare an executable CIB oracle target. The listed [CIB relationships](../../docs/CIB-BPMN-RELATION-REGISTER.md) classify the bounded start/completion and exact-token mapping extensions plus historical gateway-order calibration. Calibration does not establish whole-profile CIB equivalence, general JUEL, CIB transaction timing or exactly-once external effects.
