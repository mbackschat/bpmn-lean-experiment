# Nested embedded scope data draft profile

The [profile artifact](profile.json) selects the [nested embedded scope data specification](../../docs/capsules/NESTED-EMBEDDED-SCOPE-DATA-SPEC.md): serial ordinary embedded Sub-Processes up to definition depth three, each optionally declaring scope locals through `camunda:inputOutput`, with User Tasks and mapped Service Tasks on each serial path. Every surface uses the `SingletonBusinessItem` domain with the 1,024-byte root-String bound.

A read resolves to the nearest frame on the scope chain that declares the name, otherwise the Process; a write updates that owner and never creates a local. A User Task completion patch may name only frame-declared names on its chain and is capped at 16,384 canonical UTF-8 bytes. The [CIB relationships](../../docs/CIB-BPMN-RELATION-REGISTER.md) classify the name-based scope account as an extension; hosting capacity, public registration and independent Closure are separate claims, and the capsule owns current acceptance.
