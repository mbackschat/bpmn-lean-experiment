# CIB Seven 2.2.0 Boolean User Task completion-data draft profile

This draft profile reuses the exact sequential private executable Process of the string/null User Task profile. It admits string/null Process Start data and exact User Task completion patches containing string, null, or primitive Boolean values. It adds no checked BPMN node, Semantic Process operation, expression behavior, effect data, mapping data, or Temporal primitive.

The [profile artifact](profile.json) pins CIB Seven `2.2.0` at the reviewed source revision and selects `CIB-EXT-0010` only for the additional public Java Boolean completion fact. The existing `CIB-EXT-0005` and `CIB-EXT-0006` relationships retain their string/null scope. The [Boolean Process-data specification](../../docs/capsules/BOOLEAN-PROCESS-DATA-SPEC.md) owns the exact value-domain policy, preserved old-profile behavior, evidence obligations, and exclusions.

Its status remains `draft`. Results must not be reported as a general value system, immutable CIB compatibility, or BPMN Process Execution Conformance.
