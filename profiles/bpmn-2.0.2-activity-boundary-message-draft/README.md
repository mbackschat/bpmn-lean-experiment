# BPMN 2.0.2 interrupting Activity boundary Message draft profile

This standards profile selects one User Task carrying one omission-only interrupting, payload-free, operation-addressed Message Boundary Event. The Activity and subscription are armed atomically. Empty completion of the exact host task withdraws the subscription and follows only the normal route; exact Message delivery withdraws the host task and follows only the boundary route. Either later losing stimulus is rejected with exact state preservation while the selected follow-on task keeps the Process open.

The [profile artifact](profile.json) names BPMN 2.0.2 as semantic authority. Direct subscription addressing is a bounded profile restriction, not the general correlation account from Clauses 8.4.2, 8.4.11, and 8.5. Omitted `cancelActivity` resolves to `true` under the XSD and CMOF default. Relationships `CIB-AGR-0001` and `CIB-OP-0001` identify only the already reviewed User Task interaction and occurrence-identity premises reused by this profile; the Message Boundary Event, competition, and cancellation account selects no CIB target or retained CIB result.

The exact meaning, proof boundary, Temporal fail-closed coalescing rule, evidence obligations, and exclusions belong to the [interrupting Activity boundary Message specification](../../docs/capsules/ACTIVITY-BOUNDARY-MESSAGE-SPEC.md). Status remains `draft`; this profile makes no claim about payloads, key or context correlation, buffering before the subscription exists, non-interrupting or multiple boundaries, other Activity hosts, general cancellation, portable ordering for co-ready delivery and completion, CIB compatibility, BPMN Process Execution Conformance, or production history compatibility.
