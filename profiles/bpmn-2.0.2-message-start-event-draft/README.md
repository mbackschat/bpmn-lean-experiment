# BPMN 2.0.2 Message Start Event draft profile

The [profile artifact](profile.json) selects one payload-free, top-level Message Start Event that instantiates one private executable Process through one exact resolved Message, Interface, and Operation channel. The admitted linear Process continues through one User Task and one None End Event.

BPMN 2.0.2 is the normative authority. The exact selected meaning, forward-compatible admission restriction, host refinement, and exclusions are owned by the [Message Start Event specification](../../docs/capsules/MESSAGE-START-EVENT-SPEC.md).

`CIB-AGR-0001` and `CIB-OP-0001` apply only to the already established trailing User Task boundary. They establish no CIB Message Start compatibility claim, and this standards-only profile has no CIB target or retained CIB evidence.
