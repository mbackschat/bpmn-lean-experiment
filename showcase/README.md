# Platform showcases

This tree contains executable product-2 milestone acceptance gates. Showcases configure and drive production packages but contain no reusable production behavior and no private alternative API.

The implemented gates are [M1 third-party definition deployment](m1-definition-deployment/README.md), [M2 exact-version definition scheduling](m2-definition-scheduling/README.md), [M2 exact-version Message Start ingress](m2-message-start-ingress/README.md), [M2 definition-scoped correlated Message ingress](m2-correlated-message-ingress/README.md), [M2 Process-instance search](m2-process-instance-search/README.md), [M3 Human Work](m3-human-work/README.md), [M4 incident operations](m4-incident-operations/README.md), and [MUE Preview Alpha](mue-preview-alpha/README.md). The fixed-fixture [Product 2 UI-quality lane](platform-ui-quality/README.md) owns responsive, focus, reduced-motion, capability-disclosure, visual-regression, M5 E1 committed-execution History/Diagram/export, and per-instance Operator history/canonical-download evidence without starting Temporal or entering Product 1 verification. The [platform browser walkthrough project](platform-browser-walkthrough/README.md) is a documentation-only Playwright client of the containerized public origin; it captures no alternative product evidence. The [showcase milestone ladder](../docs/SHOWCASE-MILESTONE-LADDER-DECISION.md#showcase-milestone-ladder) owns the milestone order and exit gates.
