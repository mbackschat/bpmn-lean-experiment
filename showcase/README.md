# Platform showcases

This tree contains executable product-2 milestone acceptance gates. Showcases configure and drive production packages but contain no reusable production behavior and no private alternative API.

The implemented gates are [M1 third-party definition deployment](m1-definition-deployment/README.md), [M2 exact-version definition scheduling](m2-definition-scheduling/README.md), and [M2 exact-version Message Start ingress](m2-message-start-ingress/README.md). [PLAN.md](../docs/PLAN.md#showcase-milestone-ladder) owns the milestone order and exit gates.
