# Engine gateway

This package owns product 2's only semantic-consumption boundary: compile exact bytes, start an admitted program, observe committed state, and submit a command through narrowed public engine entry points.

Exact source compilation projects only source identity, definition identity, and admission diagnostics. Exact-definition start binds stored source, digest, profile, Process identity, semantic Process-instance identity, and Task Queue before it reaches the concrete Temporal client, then discards the SDK Workflow handle. The composition-facing runtime owns one lazy reusable client connection and idempotent closure, so no other Product 2 package imports the Temporal client package. The gateway never exposes the checked graph or Semantic Process program and never reconstructs a semantic fact from Temporal Event History, state differences, or platform persistence. Observation and command submission remain absent. See [the architecture](../../../docs/ARCHITECTURE.md#product-2-dependency-direction).
