# Engine gateway

This package owns product 2's only semantic-consumption boundary: compile exact bytes, start an admitted program, observe committed state, and submit a command through narrowed public engine entry points.

Exact source compilation is implemented and projects only source identity, definition identity, and admission diagnostics. It never exposes the checked graph or Semantic Process program and never reconstructs a semantic fact from Temporal Event History, state differences, or platform persistence. Start, observation, and command submission remain absent. See [the architecture](../../../docs/ARCHITECTURE.md#product-2-dependency-direction).
