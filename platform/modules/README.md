# Platform modules

Business modules follow durable product capabilities rather than global technical layers. Each module owns its application service, domain-specific persistence ports, HTTP route contribution, and projections.

Only the [definitions module](definitions/README.md) is implemented for M1. Work, Operate, Connect, Lifecycle, Intelligence, Agents, and Administration remain ownership seams in [ARCHITECTURE.md](../../docs/ARCHITECTURE.md#business-modules), not implemented directories.
