# Platform server

This directory contains the Node modular-monolith composition root for the public HTTP API, module wiring, and local configuration. It owns no BPMN meaning and no module business rule.

The server adapts Node HTTP requests to ordered Fetch-compatible module routes, composes definition deployment, exact-version start, source-first diagram presentation, exact-version Timer Start scheduling, global exact-version Message Start publication, Process-instance search, and the global human-work API from published package entry points. It owns one HTTP server, the definition, schedule, publication, presentation-sidecar, Process-instance, Work, and audit SQLite owners, plus one lazy reusable Temporal client connection. Startup reconciles the shared durable confirmed-start lifecycle, including describe-only direct-start recovery, before Schedule and Message recovery, route construction, or listening. Confirmed direct, Schedule, and Message starts independently deliver their exact public identity to Operate and their public identity plus private opaque locator to Work. Work aggregation observes only those locators, applies configured fake-actor policy after the complete system snapshot, and durably coordinates claims, completion, and audit delivery. Request authority comes only from the configured public origin, never from the untrusted Host header. Definition source limits remain owned by the definitions route and engine gateway; presentation generation adds a separate 1000 ms killable-worker deadline. The transport adapter streams bodies without adding another size policy.

The executable entry point defaults to `127.0.0.1:3000`, `.data/platform`, a 1 MiB source limit, a 1000 ms parser deadline, Temporal at `127.0.0.1:7233` in namespace `default`, Task Queue `bpmn-semantic`, a 5000 ms connection timeout, fake actor `demo-user` in exact groups `reviewers` and `operators`, operations group `operators`, 100 Work processes, and 1000 current tasks. Configuration is read from `PLATFORM_HOST`, `PLATFORM_PORT`, `PLATFORM_PUBLIC_ORIGIN`, `PLATFORM_DATA_DIRECTORY`, `PLATFORM_MAX_SOURCE_BYTES`, `PLATFORM_PARSER_DEADLINE_MS`, `PLATFORM_TEMPORAL_ADDRESS`, `PLATFORM_TEMPORAL_NAMESPACE`, `PLATFORM_TEMPORAL_TASK_QUEUE`, `PLATFORM_TEMPORAL_CONNECT_TIMEOUT_MS`, `PLATFORM_FAKE_ACTOR_ID`, `PLATFORM_FAKE_ACTOR_GROUPS_JSON`, `PLATFORM_OPERATIONS_GROUP_ID`, `PLATFORM_MAX_WORK_PROCESSES`, and `PLATFORM_MAX_WORK_TASKS`.
