# Platform server

This directory will contain the Node modular-monolith composition root for the public HTTP API, module wiring, configuration, and optional static asset serving. It owns no BPMN meaning and no module business rule.

M1 server behavior is not implemented yet. See [the architecture](../../../docs/ARCHITECTURE.md#applications) and [the M1 showcase](../../../showcase/m1-definition-deployment/README.md).
