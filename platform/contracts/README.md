# Platform public contracts

This package owns transport-visible HTTP and event shapes. Contracts carry no service implementation and no BPMN interpretation.

The shared runtime JSON parser accepts exactly one UTF-8 JSON value and rejects duplicate object keys after escape decoding, malformed JSON, malformed UTF-8, and unpaired Unicode surrogates before a route-specific closed decoder runs. Product 2 public HTTP owners use that neutral transport guard; persistence-owned JSON parsing is outside its boundary.

The M1 definition contract publishes exact source identity, located admission diagnostics, deployed definition versions, closed deployment, listing, and definition-version start results, route builders, API error codes, and strict unknown-to-response decoders. The diagram-presentation extension returns one exact version-bound complete BPMN presentation with explicit source or generated provenance, admitted-source digest binding, and exact presentation digest; its strict decoder recursively refuses extras and private fields. A successful start exposes only the semantic Process-instance ID bound to its exact deployed definition version. A pre-start rejection exposes that definition and one opaque failure. Temporal identity, handles, private sidecar storage, and private engine representations do not cross this boundary. The generic error decoder accepts only the explicit route-owned code set supplied by its caller while rejecting private fields and empty messages, so existing routes retain their exact legacy unions as Work adds its own codes. Engine diagnostic and start-failure codes remain opaque strings: the platform reports them but does not author their meaning.

The definition-scheduling contract adds the platform-owned Timer Start capability on every exact deployed version; closed one-shot schedule request, item, list, status, and conflict shapes; exact collection and item route builders and matchers; canonical whole-second UTC instant validation; and strict decoders that preserve exact definition and semantic Process-instance identity without admitting Temporal Schedule, Workflow, Run, task-queue, or action fields. All nested definition, capability, schedule, and instance values are immutable at compile time.

The Message Start publication contract widens every definition to exact `{ messageStarts, timerStarts }`, preserves the complete operation-addressed channel, and adds one global exact-target publication item route. Its strict pending, accepted, and indeterminate union exposes a Process-instance identity only for accepted delivery and rejects every private Workflow, Run, Task Queue, Memo, command, program, and engine field.

The Process-instance search contract reuses that exact public identity and adds one global collection request and page. It accepts only exact semantic-instance, Process, positive version, and lowercase source-digest filters plus one opaque cursor and a bounded limit. Strict route matching rejects duplicate or unknown query fields, and the response decoder preserves the complete definition and capability snapshot while rejecting private host facts.

The M3 Work contract defines the closed current-task snapshot, exact task detail and typed value compatibility, claim and release resources, retry-safe completion action, self-owned audit page, route encodings, body ceilings, and route-specific error codes. Every nested value is deeply immutable through the neutral `@bpmn-lean/contract-types` owner. Strict decoders preserve absence, null, Boolean, and string distinctions, require canonical task ordering, timestamps, and cursors, and recursively reject Workflow, Run, Task Queue, locator, intent, Memo, history, and other private fields. This package defines transport shape only; Work lifecycle and authorization remain module behavior.

The M4 incident contract adds the exact generation-1 payload-free effect incident, complete nested occurrence identity, engine-published Retry and optional root-Process Cancel interaction tuples, strict current snapshot and action results, a separate incident-action audit event and page, canonical scalar ordering, exact list/detail/action/audit routes, and route-owned error subsets. Audit filters preserve all-or-none complete incident identity, canonical millisecond UTC timestamps, bounded pages, and opaque exclusive cursors. The only new shared catalog member is `incidentSnapshotUnavailable`; every earlier route-owned accepted set remains unchanged.

The current contract deliberately excludes HTTP server behavior, persistence, engine calls, BPMN interpretation, scheduling and publication lifecycle implementation, a definition-start request body, initial variables, authentication, and UI state. [ARCHITECTURE.md](../../docs/ARCHITECTURE.md#public-contracts) owns the boundary.
